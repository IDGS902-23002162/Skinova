U2-Net-p ONNX model for local product-photo background removal.

Model: https://github.com/danielgatis/rembg/releases/download/v0.0.0/u2netp.onnx
Original project: https://github.com/xuebinqin/U-2-Net
License: Apache License 2.0 (see LICENSE in this directory).

The model edits only the background of Open Beauty Facts front photos. The original
photo remains available as a fallback if processing fails.
